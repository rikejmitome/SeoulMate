# SeoulMate Roadmap

## Development plan

Version: 1.0

Status: Active

---

# Purpose

This document defines the development roadmap for SeoulMate.

The goal is not to create a large product roadmap.

The goal is:

> Build a complete, reliable application that can be used during a real trip to South Korea.

The roadmap prioritizes:

- working functionality
- stability
- simplicity
- user experience

---

# Development Philosophy

## Complete Core Before Expansion

Development should follow this order:

1. Foundation
2. Core travel experience
3. Travel preparation
4. During-trip experience
5. Memory experience
6. Polish

---

# Development Rules

## Do Not Start New Features Before Completing Current Phase

Incomplete features create:

- complexity
- bugs
- unstable experience

---

## Prefer Working Features Over Perfect Features

A simple working feature is better than an ambitious unfinished feature.

---

# Roadmap Success Criteria

The roadmap succeeds when:

Before Korea:

The group can prepare the entire trip inside SeoulMate.

During Korea:

The group uses SeoulMate every day.

After Korea:

The group keeps SeoulMate as a memory of the journey.

---

# Final Roadmap Principle

The goal is not to build the biggest travel application.

The goal is to build the best possible companion for one Korean adventure.
