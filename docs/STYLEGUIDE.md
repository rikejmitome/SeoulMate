# SeoulMate Style Guide

## Visual identity and design system

Version: 1.0

Status: Active

---

# Purpose

This document defines the visual identity of SeoulMate.

The goal is to ensure that every part of the application feels like one consistent product.

This document guides:

- UI design
- components
- colors
- typography
- illustrations
- images
- animations
- Haechi usage

The goal is not to create a complicated design system.

The goal is to help create a beautiful, consistent and maintainable application.

---

# Design Philosophy

## Modern Korean Lifestyle

SeoulMate should feel inspired by modern South Korea.

The visual identity combines:

- Seoul lifestyle
- Korean minimalism
- modern mobile design
- warmth and hospitality
- subtle traditional inspiration

---

# The Application Should Feel Like

- a premium Korean lifestyle app
- a personal travel companion
- a calm morning in Seoul
- a beautifully designed travel journal

---

# The Application Should Not Feel Like

- a generic travel planner
- a booking application
- a tourist information website
- a gaming app
- a social network

---

# Visual Keywords

All design decisions should support these feelings:

## Calm

The interface should feel organized and stress-free.

---

## Warm

The application should feel welcoming and personal.

---

## Premium

The application should feel carefully crafted.

---

## Friendly

Users should feel accompanied.

---

## Modern

The design should represent contemporary Korea.

---

# Color System

The color system should remain simple.

Avoid excessive colors.

---

# Primary Color

## Seoul Blue

Purpose:

Main brand color.

Used for:

- primary buttons
- active navigation
- important actions
- links

The color should feel modern and calm.

---

# Secondary Color

## Haechi Gold

Purpose:

Emotional highlights.

Used for:

- achievements
- milestones
- special moments
- Haechi elements

Represents:

- good fortune
- memories
- celebration

---

# Accent Color

## Korean Coral

Purpose:

Attention and emotional emphasis.

Used for:

- favorites
- important reminders
- selected states

---

# Background Colors

## Korean Paper White

Purpose:

Main background.

The application should avoid pure white everywhere.

The feeling should resemble:

- paper
- ceramics
- traditional Korean minimalism

---

## Soft Surface

Used for:

- cards
- containers
- sections

---

# Typography

Typography should prioritize readability.

---

# Primary Font

Recommended:

Inter

Used for:

- English text
- Latin characters
- UI elements

---

# Korean Font

Recommended:

Noto Sans KR

Used for:

- Hangul
- Korean names
- Korean phrases

---

# Typography Principles

Use:

- clear hierarchy
- comfortable spacing
- readable sizes

Avoid:

- decorative fonts
- excessive font styles

---

# Layout Principles

---

# Cards Over Tables

SeoulMate is a mobile experience.

Prefer:

- cards
- sections
- visual blocks

Avoid:

- dense tables
- spreadsheet-like layouts

---

# Breathing Space

The interface should have enough empty space.

The feeling should be:

clean and calm.

---

# Clear Hierarchy

Every screen should clearly communicate:

1. What is this?
2. What is important?
3. What can I do?

---

# Primary Action

Each screen should have one obvious main action.

Avoid multiple competing actions.

---

# Components

Components should be reusable and visually consistent.

---

# App Bar

Should provide:

- screen title
- navigation context
- important actions

Avoid:

- excessive buttons

---

# Cards

Cards are a primary content container.

Used for:

- places
- activities
- memories
- information cards

Characteristics:

- rounded corners
- clean spacing
- subtle elevation

---

# Buttons

Primary buttons:

Used for important actions.

Examples:

- Save
- Add Activity
- Start Navigation

---

Secondary buttons:

Used for:

- alternative actions
- less important options

---

# Chips

Used for:

- categories
- tags
- status

Examples:

- Restaurant
- Want to Visit
- Completed

---

# Bottom Navigation

Main navigation remains:

HOME

TRIP

PLACES

BUDGET

MORE

---

# Lists

Lists should prioritize scanning.

Each item should show:

- important information first
- secondary information optionally

---

# Empty States

Empty states are part of the personality.

They should use:

- friendly language
- optional Haechi illustration

Example:

"Your Korean adventure starts here."

- real locations
- food photography
- streets
- cafés
- cultural places
- everyday Seoul life

# Iconography

Icons should be:

- simple
- modern
- consistent

- line icons
- rounded shapes

---

Avoid:

- mixing different icon styles
- overly detailed icons

# Emoji Usage

Emoji can be used selectively.

Good use:

- categories
- Haechi communication
- achievements

- replacing the entire visual system with emojis

# Haechi Design Language

Haechi is a guide, not a chatbot.

## Personality

- Friendly
- Calm
- Curious
- Encouraging
- Respectful

Haechi never interrupts the user or blocks primary tasks.

## Usage Rules

Show Haechi:
- onboarding
- empty states
- achievements
- preparation tips
- milestone celebrations

Do not show Haechi:
- forms
- payment flows
- authentication
- emergency workflows
- destructive confirmations

Haechi should always deliver short, positive and contextual messages.

# Dark Mode

Dark mode is not required for version 1.0.

Reason:

- increases development complexity
- requires additional testing
- does not provide critical travel value

However:

The architecture should not prevent future implementation.

---

# Design Rules For Codex

Codex should:

Always:

- reuse existing components
- follow defined colors
- maintain consistency
- prefer simplicity

Never:

- create random UI styles
- introduce new colors without reason
- create inconsistent screens
- copy generic Material Design without adaptation

---

# Final Visual Goal

Opening SeoulMate should feel like opening a carefully designed travel journal from Korea.

The application should communicate:

Before Korea:

"Something beautiful is coming."

During Korea:

"I have my companion with me."

After Korea:

"This journey will stay with me."
